# ashkanfaraa.com

Personal site, built with [Next.js](https://nextjs.org) 16, React 19, and TypeScript, styled with Tailwind CSS v4. Includes Stripe-based checkout for paid content.

Live: https://ashkanfaraa-com.vercel.app

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
